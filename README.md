# stt_kor
로컬 STT(Speech-to-Text) 기능을 사용하기 위한 사용자 편의주의 프로그램

## AI는 정확하지 않을 수 있습니다. 수업 자료 / 기타 PDF 등을 참고해 노트와 대조하여 특정 단어 오류 등을 캐치하시길 바랍니다.
권장 사용방법: stt_kor로 만든 Transcript + 자료 -> LLM을 통해 노트나 Transcript 수정.

## 편의 기능
- **인식 언어**를 한국어 / English / 자동 감지 중에서 고를 수 있습니다. 마지막으로 고른 언어를 기억합니다. (v1.0.7 이상)
- **영어 강의는 English를 고르세요.** medium 이하를 쓰는 경우 같은 등급의 영어 전용 모델로 자동으로 바꿔 돌려서 더 정확합니다 (medium 자리는 distil 판이라 용량이 절반이고 더 빠릅니다). 단 영어 전용 모델은 **강의 중 한국어가 섞이면 그 구간을 잘못 인식**하므로, 영어와 한국어가 섞이는 수업이면 `turbo`나 `large-v3`를 쓰세요. 자동 감지에서는 영어 전용 모델을 쓰지 않습니다. (v1.0.9 이상)
- **`turbo` 모델**을 추가했습니다. large-v3와 품질은 사실상 같은데 파일은 절반(약 1.6GB), 속도는 몇 배 빠르고 VRAM도 절반이라, 예전에 medium으로 내려가던 중급 GPU에서도 최고 품질을 쓸 수 있습니다. NVIDIA GPU가 있으면 기본 권장 모델이 됩니다. (v1.0.9 이상)
- 마지막으로 쓴 **오디오 폴더**와 **출력 폴더**를 기억합니다. 매번 처음부터 찾아 들어갈 필요가 없습니다.
- 새 버전이 나오면 실행할 때 **알림 창**으로 알려줍니다. 패치노트를 보고 [지금 업데이트]를 누르면 설치 파일을 받아 그대로 설치합니다. (v1.0.5 이상에서 동작)

## 개발자 옵션 (CLI)
소스로 실행할 때 인자를 주면 창을 띄우지 않고 터미널에서 바로 변환합니다. 인자가 없으면 지금처럼 GUI가 뜹니다.

설치본(exe)을 쓰는 일반 사용자는 신경 쓰지 않아도 됩니다. CLI를 쓰려면 설치 마법사 대신 **이 저장소를 받아 소스로 실행**하세요.

### 준비
```
git clone https://github.com/NombarHwan/stt_kor.git
cd stt_kor
pip install -r requirements.txt
python stt_app.py --help
```

- **Python 3.10 이상**이면 됩니다 (릴리스 빌드는 3.12, 개발 환경은 3.14에서 동작 확인). python.org 설치본에 tkinter가 들어 있어 GUI도 그대로 뜹니다.
- **ffmpeg를 따로 깔 필요 없습니다.** 오디오 디코딩은 PyAV에 포함된 바이너리가 처리합니다.
- **설정·모델 캐시·CUDA 라이브러리를 설치본과 공유**합니다(`%LOCALAPPDATA%`). 설치본을 쓰던 PC라면 기억해 둔 폴더와 이미 받아둔 모델을 그대로 재사용합니다.
- **GPU(선택)**: NVIDIA GPU가 있으면 첫 변환 때 CUDA 라이브러리(약 1.3GB) 다운로드 여부를 물어보고 `%LOCALAPPDATA%`에 캐싱합니다. pip로 직접 넣고 싶다면 아래를 설치해도 인식합니다.
  ```
  pip install nvidia-cublas-cu12==12.9.2.10 nvidia-cudnn-cu12==9.25.1.1 nvidia-cuda-nvrtc-cu12==12.9.86
  ```
- 업데이트는 `git pull`입니다. 앱 내장 자동 업데이터(설치본 덮어쓰기)는 소스 실행에는 관여하지 않습니다.

### 사용법
```
python stt_app.py 0910                    # 녹음 폴더에서 이름에 0910이 든 오디오 전부
python stt_app.py 컴퓨터구조 정보보호      # 검색어 여러 개
python stt_app.py D:/rec/강의.m4a         # 파일 경로 직접 지정
python stt_app.py --list                  # 녹음 폴더의 오디오 목록만 보기
python stt_app.py --help                  # 전체 옵션
```

| 옵션 | 설명 |
| --- | --- |
| `-m, --model` | `large-v3 / turbo / medium / small / base / tiny` (기본: 하드웨어에 맞춰 자동 선택) |
| `-l, --lang` | `ko / en / auto` (기본: 설정에 기억된 언어) |
| `-i, --input-dir` | 녹음 폴더 (기본: GUI에서 마지막으로 쓴 폴더) |
| `-o, --output-dir` | 결과 저장 폴더 (기본: 설정값, 없으면 원본 옆) |
| `-f, --force` | 결과 파일이 이미 있어도 다시 변환 |
| `--gpu` / `--cpu` | CUDA 라이브러리 다운로드 여부를 묻지 않고 결정 |
| `--save` | 이번에 준 폴더·언어를 기본값으로 기억 (GUI와 같은 설정 파일) |

### 처음 한 번만: 녹음 폴더 지정
검색어로 찾으려면 어느 폴더를 뒤질지 알려줘야 합니다. GUI에서 오디오 파일을 한 번 고르면 그 폴더를 기억하므로 그대로 쓰면 되고, CLI에서 직접 지정하려면 `--save`를 붙입니다.

```
python stt_app.py -i "C:/Users/heosu/OneDrive/Documents/소리 녹음" --save
```

이후로는 검색어만 주면 됩니다.

```
> python stt_app.py 0910
검색 결과 2개 파일 발견:
  - 정보보호와시스템보안_0910.m4a
  - 컴퓨터구조_0910.mp3

모델 자동 선택: turbo - NVIDIA GPU 감지 - 최고 품질(turbo)을 빠르게 쓸 수 있습니다.
인식 언어: 한국어
[1/2] 정보보호와시스템보안_0910.m4a
  [   0.0s →    5.2s] 오늘은 접근 통제부터 보겠습니다.
  ...
  저장 완료: ...\정보보호와시스템보안_0910_transcript.txt
```

### 참고
- 설정 파일·모델 캐시·CUDA 라이브러리는 GUI와 공유하므로 둘을 섞어 써도 됩니다.
- 검색어는 파일 이름의 부분 일치(대소문자 무시)이며, 하위 폴더는 찾지 않습니다. 오디오 확장자(mp3/wav/m4a/mp4/aac/flac/ogg/wma)만 대상입니다.
- 검색어를 여러 개 주면 각각 찾아서 전부 변환하고, 중복은 한 번만 처리합니다.
- 결과 파일이 이미 있으면 건너뜁니다. 다시 만들려면 `-f`.
- 설치본(exe)도 cmd/PowerShell에서 실행하면 같은 인자를 받습니다. 다만 창 없이 빌드된 프로그램이라 출력이 프롬프트와 섞여 보일 수 있고, 콘솔 없이 실행하면(바로가기 더블클릭 등) 인자를 무시하고 GUI가 뜹니다. CLI는 소스 실행(`python stt_app.py`)을 기준으로 만들었습니다.
