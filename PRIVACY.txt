Transcribe to Learn
Privacy Policy(개인정보 처리방침)

최종 수정일: 2026-09-24


Transcribe to Learn은 어떠한 종류의 개인정보도 저장 또는 공유하지 않는 애플리케이션입니다.

Transcribe to Learn은 OpenAI의 Whisper 모델과 할루시네이션 방지 코드로 음성을 인식합니다.
인식은 전부 사용자의 PC 안에서 실행됩니다. 변환하는 오디오 파일과 그 결과로 만들어진
텍스트는 사용자의 PC를 벗어나지 않으며, 개발자를 포함한 어떤 서버로도 전송되지 않습니다.

Transcribe to Learn은 계정, 로그인, 사용 기록 수집, 광고, 분석 도구를 사용하지 않습니다.

Transcribe to Learn은 마이크를 사용하지 않습니다. 녹음 기능이 없으며, 사용자가 이미 가진
오디오 파일을 읽습니다.


PC에 저장하는 것

Transcribe to Learn은 마지막으로 사용한 오디오 폴더와 출력 폴더, 인식 언어를 기억합니다.
내려받은 음성 인식 모델과 GPU 가속용 CUDA 라이브러리도 다시 받지 않도록 보관합니다.
모두 사용자의 PC에만 저장되고 외부로 전송되지 않으며, 앱을 삭제하면 함께 지워집니다.


인터넷을 사용하는 경우

Transcribe to Learn이 인터넷에 접속하는 경우는 다음 세 가지이며, 어느 경우에도 사용자의
오디오나 텍스트를 보내지 않습니다.

  1. 선택한 음성 인식 모델을 처음 사용할 때 Hugging Face(huggingface.co)에서 내려받습니다.
  2. NVIDIA 그래픽카드가 있고 사용자가 대화상자에서 동의한 경우에만, GPU 가속용 CUDA
     라이브러리를 PyPI(pypi.org)에서 내려받습니다. 동의하지 않으면 CPU로 동작합니다.
  3. GitHub 배포판은 새 버전이 있는지 확인합니다. Microsoft Store 배포판은 스토어가
     업데이트를 담당하므로 이 기능이 꺼져 있습니다.

모델을 한 번 내려받은 뒤에는 인터넷 연결 없이 변환할 수 있습니다.
